# Golden Lotus Hotel — website

A clean, responsive static website built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page content and structure
- `style.css` — layout, responsive styles and motion
- `script.js` — EN / TR / RU / DE language switcher, mobile navigation and scroll reveals

## Run locally
Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

## Publish with GitHub Pages
1. Upload the three website files to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.

## Before publishing
The images are currently illustrative Unsplash photos. Replace them with approved Golden Lotus Hotel photography. Check the reservation URL and contact details with the hotel. This is an independent redesign concept, not an official hotel website.
